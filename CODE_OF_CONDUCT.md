# Code of conduct

Keep project discussions welcoming and focused on the work. Share feedback about the code, documentation, or results with enough detail for someone else to respond. Harassment, personal attacks, discrimination, and sharing someone else's private information without permission are unacceptable.

If an issue or pull request contains harmful content, contact the maintainer through GitHub or use GitHub's reporting tools. Maintainers may remove comments or limit participation to keep the project usable for everyone.
