Diamond OFX is my personal project. I’m studying Game Design, and I started this because I wanted a camera shake effect for my VEGAS edits. I vibe coded it with AI and put the source up here in case anyone wants to see how it works or mess with it.

There are 11 effects in v0.03. The five new ones are `D_UltraZap`, `D_PixelSort`, `D_RackDefocus`, `D_LightLeak`, and `D_FilmEffect`. The six effects from v0.02 are still there with the same IDs and controls.

## Install

1. Download `Diamond-0.03-Win64.zip` under **Assets** and extract it.
2. Close VEGAS. If you already have Diamond installed, move the old `Diamond.ofx.bundle` out of the plug-in folder.
3. Copy the new `Diamond.ofx.bundle` folder to `C:\Program Files\Common Files\OFX\Plugins\`.
4. Reopen VEGAS and look under **Video FX → Diamond**.

I tried `D_Shake` from v0.01 in VEGAS Pro 23 Steam Edition and it worked for me. I still need to try v0.03 in VEGAS. This is an unsigned Windows x64 build that renders on the CPU.

Use **Source code (zip)** to download the source and `SHA256SUMS.txt` to verify the Win64 ZIP. Diamond is MIT licensed. The included OpenFX headers use the BSD 3-Clause license.
